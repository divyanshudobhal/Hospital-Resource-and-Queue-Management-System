Hospital Resource and Queue Management System

Database folder structure:

PATIENT/
  ├── patient_id
  ├── name
  ├── age
  ├── gender
  ├── condition
  ├── priority
DOCTOR/
  ├── doctor_id
  ├── name
  ├── specialization
  ├── availability
APPOINTMENT/
  ├── appointment_id
  ├── patient_id
  ├── doctor_id
  ├── date
  ├── status
QUEUE/
  ├── queue_id
  ├── patient_id
  ├── priority
  ├── arrival_time
  ├── status
BED/
  ├── bed_id
  ├── type
  ├── department
  ├── status
EQUIPMENT/
  ├── equipment_id
  ├── type
  ├── status
RESOURCE_ALLOCATION/
  ├── allocation_id
  ├── patient_id
  ├── resource_id
  ├── allocated_at
  ├── released_at
